Neon Snake

A polished, standalone Snake game built with plain HTML, CSS, and JavaScript.

Features

Neon-colored snake and food on a dark canvas
Subtle grid background
Score and best-score tracking
Best score saved in the browser with localStorage
Increasing game speed as the score grows
Game-over screen with restart button
Keyboard controls and touch-friendly controls
Responsive layout for desktop and mobile screens
No server, build step, or dependencies required

Run locally

Open index.html directly in a web browser:

index.html

The game works without a local server.

Controls

Keyboard

Arrow keys or W, A, S, D to move
Press Space to restart after game over

Touch

Use the directional buttons below the game board on smaller screens.

Publish with GitHub Pages

Create a GitHub repository.
Upload index.html and README.md to the repository root.
Open the repository's Settings.
Select Pages.
Under Build and deployment, choose Deploy from a branch.
Select the main branch and the / (root) folder.
Click Save.

After deployment, the game will be available at:

https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/

Replace YOUR-USERNAME and YOUR-REPOSITORY with your GitHub username and repository name.
